# Project internals: study guide

These notes are for learning the code. They describe the local copies inspected
on 3 November 2026. A repository can change after this review. Check the current
code before you rely on a detail. The notes do not claim that every feature is
complete or works in the hosted version.

Start with [Amer](amer.md). Then choose a project and trace one request from the
interface to its data source. Use sample data and local copies for exercises.

1. [Amer](amer.md) — React interface, permissions, and API layers.
2. [Cortex](cortex.md) — collaborative notes, AI, and academic data.
3. [Tamatem](tamatem.md) — study sessions, web app, API, and extensions.
4. [Autonatic](autonatic.md) — Obsidian plugin, providers, and vault index.
5. [Job Aggregator](job-aggregator.md) — ingestion, storage, and search.
6. [Go Boilerplate](go-boilerplate.md) — startup, routing, and infrastructure.
7. [Inventory](inventory.md) — React screens and the desktop API boundary.
8. [Voice Typer](voice-typer.md) — audio, transcription, and system input.
9. [SBC Solver](sbc-solver.md) — browser extension and constraint solver.
10. [Offline Music Library](offline-music.md) — iPhone app, local storage, and backend.

The [portfolio research](../portfolio-project-research.md) tracks screenshots,
links, and work that remains. These study notes and the portfolio descriptions
serve different purposes.
